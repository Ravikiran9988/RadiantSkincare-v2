**RadiantSkincare** is an AI-powered personalized skincare platform. It combines deep learning computer vision (ResNet50), machine learning product recommendation engines (scikit-learn), personalized skincare routine building, AI screening history tracking, and ingredient intelligence.

---

## ⚠️ Important Medical Disclaimer

> [!IMPORTANT]
> **Medical Notice**: All AI skin disease predictions and screening results generated by RadiantSkincare are intended solely for educational and preliminary screening assistance. They **do not** constitute a medical diagnosis. Users must consult a qualified healthcare professional for clinical evaluation.

---

## ✨ Core Features

- **🔬 ResNet50 Skin Disease Screening (Model 1)**: Instant deep learning computer vision classification across 23 dermatological categories with prediction confidence scoring and safety callouts.
- **🧴 AI Product Recommendation Engine (Model 2)**: Ingredient-matching machine learning recommendation engine tailored to user skin concerns and skin types.
- **📋 Daily Skincare Routine Builder**: Interactive Morning and Evening skincare protocol checklist with step completion persistence.
- **📈 AI Screening History & Progress Tracker**: Historical log of screening records and model prediction confidence trends over time.
- **🧪 Ingredient Intelligence**: Formulation science breakdown of active ingredients (Niacinamide, Salicylic Acid, Hyaluronic Acid, Ceramides, Vitamin C).
- **☀️ Climate-Aware Guidance**: Weather detection integration providing real-time climate skin recommendations.
- **🔐 Secure User Authentication**: JWT token authorization, OTP email verification via Nodemailer, and bcrypt password hashing.

## 🔑 Environment Variables Configuration

Copy `.env.example` to `.env` in the respective subdirectories before starting the services:

### Backend (`Backend/.env`)
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/radiantskincare
JWT_SECRET=your_jwt_secret_key_here
FRONTEND_URL=http://localhost:5173
MODEL1_URL=http://localhost:5003
MODEL2_URL=http://localhost:5004
EMAIL_USER=your_email@example.com
EMAIL_PASS=your_email_app_password
```

### Frontend (`Frontend/.env`)
```env
VITE_API_URL=http://localhost:5000/api
VITE_MODEL1_URL=http://localhost:5003
VITE_MODEL2_URL=http://localhost:5004
VITE_WEATHER_API_KEY=your_openweathermap_api_key
```

## 🚀 Quick Start & Local Development

### 1. Backend Service
```bash
cd Backend
npm install
npm start             # Starts Express server on http://localhost:5000
```

### 2. Frontend Web Application
```bash
cd Frontend
npm install
npm run dev           # Starts Vite dev server on http://localhost:5173
```

### 3. Model 1 (ResNet50 Vision Classifier)
```bash
cd model1
pip install -r requirements.txt
python app.py         # Starts Flask service on http://localhost:5003
```

### 4. Model 2 (Product Recommendation Engine)
```bash
cd model2
pip install -r requirements.txt
python app.py         # Starts Flask service on http://localhost:5004
```
