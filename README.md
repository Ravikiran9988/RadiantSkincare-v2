**RadiantSkincare** is a full-stack, production-ready AI skincare intelligence and telehealth platform. It combines deep learning computer vision (ResNet50), machine learning product recommendation models (scikit-learn), real-time doctor-patient consultation rooms (Socket.IO), and intelligent weather-aware skincare insights.

## ✨ Features

- **🔬 ResNet50 Skin Disease Screening (Model 1)**: Instant deep learning computer vision classification across 23 dermatological conditions with confidence scoring and safety callouts.
- **🧴 AI Product Recommendation Engine (Model 2)**: Ingredient-matching machine learning recommendation engine tailored to user skin concerns and skin types.
- **👨‍⚕️ Board-Certified Telehealth Consultations**: Secure doctor registration, consultation scheduling, and patient assignment.
- **💬 Real-Time Encrypted Socket.IO Chat**: Room-based instant messaging between patients and assigned dermatologists with dual persistence.
- **☀️ Weather-Aware Skincare Assistant**: Live weather detection via OpenWeather API providing real-time climate recommendations.
- **📋 Daily Routine Checklist & Analysis History**: Persistent tracking of daily skincare steps and historical screening logs stored in MongoDB.
- **🔐 Secure Authentication & Authorization**: JWT token authorization, OTP email verification via Nodemailer, bcrypt password hashing, and role-based access control (User vs. Doctor).

## 🔑 Environment Variables Configuration

Copy `.env.example` to `.env` in the respective subdirectories before starting the services:

### Backend (`Backend/.env`)
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/radiantskincare
JWT_SECRET=your_jwt_secret_key_here
FRONTEND_URL=http://localhost:5173
MODEL1_URL=http://localhost:5003
MODEL2_URL=http://localhost:5004
EMAIL_USER=your_email@example.com
EMAIL_PASS=your_email_app_password
```

### Frontend (`Frontend/.env`)
```env
VITE_API_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
VITE_MODEL1_URL=http://localhost:5003
VITE_MODEL2_URL=http://localhost:5004
VITE_WEATHER_API_KEY=your_openweathermap_api_key
```

### Model 1 (`model1/.env`)
```env
PORT=5003
FRONTEND_URL=http://localhost:5173
BACKEND_URL=http://localhost:5000
```

### Model 2 (`model2/.env`)
```env
PORT=5004
FRONTEND_URL=http://localhost:5173
BACKEND_URL=http://localhost:5000
```

## 🚀 Quick Start & Local Development

### 1. Backend Service
```bash
cd Backend
npm install
node seedDoctors.js   # Seed initial doctor profiles (optional)
npm start             # Starts Express server on http://localhost:5000
```

### 2. Frontend Web Application
```bash
cd Frontend
npm install
npm run dev           # Starts Vite dev server on http://localhost:5173
```

### 3. Model 1 (ResNet50 Vision Classifier)
```bash
cd model1
pip install -r requirements.txt
python app.py         # Starts Flask service on http://localhost:5003
```

### 4. Model 2 (Product Recommendation Engine)
```bash
cd model2
pip install -r requirements.txt
python app.py         # Starts Flask service on http://localhost:5004
```

## 🛡️ Security Highlights

- **Sanitized Repositories**: All database strings, JWT keys, and SMTP credentials removed from source files. `.env` and `uploads/` untracked.
- **File Upload Security**: Allowed MIME types (`image/jpeg`, `image/png`, `image/webp`), 5MB file cap, unique random hex filenames, and path traversal protection.
- **Express Protection**: CORS restricted to `FRONTEND_URL`, JSON body size limit (10MB), and centralized error handling middleware preventing internal stack trace leaks.
- **Role Isolation**: User routes require User JWT; Doctor routes enforce `authenticateDoctor` middleware.
